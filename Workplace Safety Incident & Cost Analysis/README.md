# Workplace Safety Incident & Cost Analysis

## 📊 Project Overview
This project analyzes workplace safety records containing **514 incident reports** across multiple manufacturing plants, departments, and shifts. The goal is to identify high-risk areas, evaluate financial impacts (days lost and incident costs), and provide data-driven recommendations for safety improvements.

## 🗂️ Dataset Structure
The dataset (`sampledatasafety.xlsx`) includes the following key fields:
- **Date & Time:** Incident timestamp, broken down by weekday, month, and year (spanning 2025–2027).
- **Incident Details:** Incident Type (e.g., Burn, Cut, Fall, Lifting), Injury Location, and Severity.
- **Operational Context:** Plant location, Department, Shift, and Report Type (Near Miss, First Aid, Lost Time).
- **Financial & Productivity Impact:** Days Lost and Total Incident Cost.
